# Шаблон коммерческого предложения — PlantUp

## Продукт

**PlantUp** — готовый SaaS-маркетплейс «ферма → покупатель» с подпиской, корзиной, доставкой и тремя кабинетами.

Подходит для:
- локальных фермерских кооперативов
- городских сервисов доставки BIO-продуктов
- food subscription клубов
- white-label запуска в новом городе / стране

## Что получает покупатель

- Полный исходный код (frontend + backend + Prisma)
- 3 роли: покупатель, фермер, администратор
- Подписки (1 / 3 / 12 мес), корзина, заказы
- Интеграции: Comgate (платежи), Cloudinary (медиа)
- i18n лендинга: CS / RU / EN
- Эко-позиционирование (10% прибыли → посадка деревьев)
- Деплой-конфиг: Vercel + Railway
- Документация: SECURITY, PRODUCTION, INCIDENT_RUNBOOK
- Тесты + CI (`npm run verify`)
- Демо-пакет: sales deck + собранный UI (`app/`)
